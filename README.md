# Diabetes-Detection1

Predicting Diabetes using ML classifiers

## 📌 Project Description
This project uses various machine learning classifiers to predict whether a person has diabetes based on medical attributes. The dataset used is the Pima Indians Diabetes Dataset.

## 📁 Files
- `project.ipynb`: Main Jupyter Notebook for the analysis and model building.
- `README.md`: This file, containing project information.

## ⚙️ Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas
- NumPy
- Matplotlib / Seaborn

## 📊 ML Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## 🧪 Dataset
- Pima Indians Diabetes Dataset from Kaggle/UCI
- Features include: Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age

## ⚖️ Handling Imbalance
- SMOTE (Synthetic Minority Over-sampling Technique) was used to address class imbalance.

## ✅ Results
Model performance was evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC Curve
