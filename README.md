
# Diabetes-Detection1

Predicting Diabetes using ML classifiers

## 📌 Project Description
This project aims to predict the presence of diabetes using various machine learning models. The dataset used is the Pima Indians Diabetes Dataset, which includes medical diagnostic measurements.

## 📁 Files
- `project.ipynb`: Jupyter Notebook containing data preprocessing, model building, evaluation, and conclusions.
- `README.md`: Project documentation.

## ⚙️ Technologies Used
- Python
- Jupyter Notebook
- Scikit-learn
- Pandas
- NumPy
- Matplotlib / Seaborn
- XGBoost
- GAN (Generative Adversarial Networks)

## 📊 ML Algorithms Used
- Random Forest
- Support Vector Machine (SVM)
- XGBoost

## 🧪 Dataset
- **Source**: Pima Indians Diabetes Dataset
- **Features**: Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age

## ⚖️ Handling Imbalanced Data
To address class imbalance, we used the following methods:
- **SMOTE (Synthetic Minority Over-sampling Technique)**: Synthetic samples were generated for the minority class.
- **GAN (Generative Adversarial Networks)**: Used to generate more realistic synthetic data to balance the dataset.

## ✅ Evaluation Metrics
Models were evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- Support
